Requisitos Funcionais e Não Funcionais — AcessaFácil

1. Requisitos Funcionais

Os requisitos funcionais descrevem as funções que o sistema AcessaFácil deverá realizar.

RF01 — Cadastro de ambientes

O sistema deverá permitir que o administrador cadastre os ambientes da escola, informando nome, localização, descrição e recursos de acessibilidade disponíveis.

RF02 — Consulta de ambientes

O sistema deverá permitir que os usuários consultem os ambientes cadastrados na escola.

RF03 — Visualização das informações de acessibilidade

O sistema deverá apresentar as informações de acessibilidade de cada ambiente, incluindo os recursos disponíveis.

RF04 — Registro de problemas

O sistema deverá permitir que o usuário registre problemas relacionados à acessibilidade de um determinado ambiente.

RF05 — Acompanhamento de problemas

O sistema deverá permitir que os usuários acompanhem o status dos problemas registrados.

RF06 — Atualização de problemas

O administrador deverá poder atualizar o status de um problema, indicando, por exemplo, se está pendente, em andamento ou resolvido.

RF07 — Identificação do usuário

O sistema deverá permitir identificar o usuário responsável pelo registro de uma ocorrência.

RF08 — Busca de ambientes

O sistema deverá permitir que o usuário pesquise ou localize um ambiente específico da escola.

RF09 — Gerenciamento de informações

O administrador deverá poder alterar ou atualizar as informações dos ambientes e seus recursos de acessibilidade.

⸻

2. Requisitos Não Funcionais

Os requisitos não funcionais definem características de qualidade e funcionamento que o sistema deverá possuir.

RNF01 — Usabilidade

O sistema deverá possuir uma interface simples, clara e fácil de utilizar.

RNF02 — Acessibilidade

A interface deverá seguir boas práticas de acessibilidade digital, facilitando o uso por pessoas com diferentes necessidades.

RNF03 — Responsividade

O sistema deverá funcionar adequadamente em computadores, tablets e celulares.

RNF04 — Segurança

Os dados dos usuários e das ocorrências deverão ser protegidos contra acessos não autorizados.

RNF05 — Desempenho

As páginas e consultas deverão apresentar um tempo de resposta adequado, evitando lentidão durante a utilização.

RNF06 — Disponibilidade

O sistema deverá estar disponível para consulta sempre que a infraestrutura estiver funcionando corretamente.

RNF07 — Manutenibilidade

O sistema deverá possuir uma estrutura organizada para facilitar futuras correções, atualizações e melhorias.

RNF08 — Compatibilidade

O sistema deverá funcionar nos principais navegadores utilizados atualmente.

RNF09 — Integridade dos dados

As informações cadastradas deverão ser armazenadas de forma organizada, evitando perda ou alteração indevida dos dados.

RNF10 — Escalabilidade

A estrutura do sistema deverá permitir a inclusão de novos ambientes, usuários e informações de acessibilidade conforme a necessidade da escola.
